# 🛡️ 求职避坑共享平台

> **用真实用户的面试/求职记录，反向监督企业招聘诚信 —— 求职界的「大众点评」**

---

## 一、项目定位

### 一句话描述
一个 UGC 驱动的企业口碑查询平台：求职者分享真实的面试经历、HR 对话、招聘信息截图，帮助其他人提前识别「坑公司」。

### 目标人群

| 人群 | 痛点 | 使用场景 |
|---|---|---|
| **应届毕业生** | 缺乏面试经验，容易被画饼 / 忽悠 | 面试前搜公司名，看前人踩坑记录 |
| **社招跳槽者** | 不想浪费时间在不靠谱的面试上 | 筛选面试邀请时快速查询公司口碑 |
| **求职社区贡献者** | 有过糟糕面试经历，想发声提醒他人 | 上传记录，获得会员权益 |

### 核心价值

- 🎯 **信息对称** — 打破招聘中企业 vs 求职者的信息不对等
- 🔍 **真实 UGC** — 每条记录都来自真实求职者，平台只做审核不做修改
- 🏷️ **智能标签** — AI 自动分析风险词、薪资异常、JD 雷同（后续迭代）
- 🗺️ **城市化** — 同一公司不同城市分开评价，精准定位

## 二、功能总览

### ✅ 已实现（MVP）

#### 🔍 公司搜索与详情
- **模糊搜索** — 支持公司全称 / 简称 / 品牌名搜索
- **城市筛选** — 按城市过滤记录，跨城市自动推荐兜底
- **公司主页** — 基本信息、可信度评分、风险标签、用户记录流
- **评分系统** — 基于用户记录自动计算 0-100 分

#### 📤 用户上传系统
- **三类记录** — HR 对话记录、面试经历、招聘 JD 快照
- **问卷式展开** — 点击标题展开表单，可同时填写多项，逐个提交
- **图片上传** — 支持截图上传（PNG/JPEG/WebP/GIF，最大 10MB）
- **省市联动** — 先选省份再选城市，精准定位
- **公司自动创建** — 输入不存在的公司名自动创建条目

#### 👤 用户系统
- **免密登录** — 输入手机号或邮箱直接登录 / 注册
- **会员天数** — 每通过审核一条记录 +1 天会员
- **顶部菜单** — 显示头像、脱敏标识符、剩余会员天数

#### 📋 内容审核后台
- **管理员登录** — 独立后台（admin / admin123）
- **审核操作** — 待审核列表、通过 / 拒绝
- **自动评分** — 根据通过/拒绝记录自动更新公司可信度评分
- **自动会员** — 审核通过自动给上传者加 1 天会员

#### 🚩 举报系统
- **用户举报** — 每条记录可举报
- **自动处理** — 同条记录被举报 ≥3 次自动拒绝

#### 🎬 广告与激励
- **激励视频广告** — 查看记录前展示 30 秒广告（MVP 为占位）
- **会员免广告** — 有会员天数直接跳过

#### 🛡️ 合规与安全
- 用户协议 & 免责声明
- 安全响应头（XSS/Content-Type/Frame）
- PWA 支持（manifest + 图标）

## 三、技术栈

| 层 | 技术选型 |
|---|---|
| **前端框架** | Next.js 16.2 (App Router) + React 19 |
| **样式** | Tailwind CSS 4 |
| **语言** | TypeScript 5 |
| **数据库** | SQLite (Prisma 7 ORM) — 可平滑切换 PostgreSQL |
| **认证** | 无密码 / 手机号邮箱直接登录 |

| **构建工具** | Turbopack |

## 四、快速启动

```bash
# 1. 安装依赖
npm install

# 2. 初始化数据库 + 种子数据
npm run seed

# 3. 启动开发服务器
npm run dev
# → http://localhost:3000

# 4. 生产构建
npm run build
npm start
```

## 五、项目结构

```
src/
├── app/
│   ├── page.tsx                  # 首页（搜索 + 热门公司）
│   ├── layout.tsx                # 全局布局（导航栏 + 用户菜单）
│   ├── upload/page.tsx           # 上传表单（登录门控）
│   ├── companies/[id]/           # 公司详情页
│   ├── search/page.tsx           # 搜索结果
│   ├── admin/                    # 审核后台
│   ├── privacy/page.tsx          # 免责声明
│   └── api/                      # API 路由
├── components/
│   ├── SearchBox.tsx             # 搜索框 + 城市筛选
│   ├── CityPicker.tsx            # 省市联动选择器
│   ├── RecordCard.tsx            # 记录卡片（含举报）
│   └── UserMenu.tsx              # 用户登录菜单
├── lib/
│   ├── prisma.ts                 # Prisma 单例
│   └── cities.ts                 # 省市数据
└── types/index.ts                # 类型定义
```

## 七、部署建议

| 方案 | 推荐指数 | 说明 |
|---|---|---|
| VPS 直接跑 | ⭐⭐⭐⭐⭐ | 最简单，`npm start` 即可 |
| Docker 单容器 | ⭐⭐⭐⭐ | 需要写 Dockerfile |
| Docker Compose | ⭐⭐⭐ | 如需 PostgreSQL + 持久卷 |

> **数据库说明**：MVP 使用 SQLite 无需额外配置。
> 用户量大后可切换 PostgreSQL，只需修改 `prisma/schema.prisma` 中的 `provider` 和连接串。
